# Bakebok frontend

The recipe site is built with Vite, React 18, Chakra UI, and Sanity.

## Local development

1. Copy `.env.example` to `.env` and fill in the Sanity project ID and dataset.
2. Run `npm install`.
3. Run `npm run dev` and open the displayed local URL.

## Production

Run `npm run build` to generate the production site in `dist/`. Vercel uses this command and directory through the repository configuration.
